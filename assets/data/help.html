Library App (release v.1.0 beta)

Troubleshooting guide & recovery instructions

Troubleshoot

Below are the error codes you may encounter and their common causes and fixes.

Error code 101 — Integrity Error

This error may happen for the following cases:

  • Trying to add a book or user that already exists.
  • Trying to issue a book with a book number or cadet number that has not been added.
  • Trying to deposit (return) a book that was never issued.

Error code 102 — Operational Error

This error may happen for the following cases:

  • Using double or single quotes (" or ') in names. Avoid them to prevent SQL issues.
  • Putting alphabetic characters or ordinal suffixes where integers are required. Example: use 43 instead of 43rd for batch numbers.
  • In many cases this error arises from internal bugs; if you cannot resolve it, contact the developer.

Data loss — possible causes

  • Sudden shutdown of the PC (power loss, crash).
  • Switching Windows user accounts while the app was running.
Tip: The app keeps backup copies — try restoring from the backups folder first (instructions below).

Solution — Restore from backup

Follow these steps to restore the latest backup of the application's database:

  1. Open your User folder on the C:\ drive. Example path: C:\Users\<YourUserName>.
  2. Navigate to: AppData\Local\Library\Backups\lib. (Note: AppData is hidden by default — enable "Show hidden files" in File Explorer if needed.)
  3. The backup files are timestamped. Choose the most recent file and rename it to library.db.
  4. Copy (or cut) that library.db and replace the existing library.db file in the application's main Library folder.
Warning: Always keep a copy of the original files before replacing them. If unsure, copy the backup to a safe location first.
